# What’s New

## 1.0.2.3

- Added **Update** and **Install and Relaunch** for signed in-app updates. Syllabi saves course changes before replacing the app.
- Fixed update discovery in the macOS sandbox and added **Check for Updates** in the sidebar.
- Added **Copy Syllabus Markdown**. Empty replacement files now leave the existing syllabus intact.
- Improved math notation in syllabi, import previews, and lesson lists.

Install this first Sparkle-enabled release from `Syllabi.dmg`. Subsequent signed releases can install and relaunch from the app.

## 1.0.0

- Added a consistent, responsive top navigation bar.
- Refined the palette for calmer surfaces and better light/dark mode contrast.
- Added GitHub Releases update discovery and one-click DMG download.
- Added an in-app What’s New screen for every release.
