# Syllabi 📚
> Local-First Notion-Style Syllabus Tracker for macOS

Syllabi is a native macOS desktop application designed for students and self-learners to track academic curriculum progress topic-by-topic.

## Key Features

- **Standardized AI Syllabus Import (`.md`):** Drag-and-drop or upload `.md` files generated by any LLM (ChatGPT, Claude, Gemini) or paste Markdown directly into the live preview importer.
- **AI Formatter Prompt Generator:** One-click "Copy AI Prompt" to generate perfectly formatted Markdown from any course syllabus or PDF outline.
- **Notion-Style Native Workspace:**
  - Collapsible Unit disclosure toggles with live fractional & linear progress bars.
  - Interactive checkboxes with smooth completion animations and strike-through styling.
  - Subtopic support: nested checklists with automated two-way parent-child completion synchronization.
  - Inline editing for subject titles, codes, terms, units, and topic titles.
  - Clickable emoji selector for subject icons and color theme picker.
  - Inline expandable study notes blockquote editor (`> `).
- **Search & Filtering:**
  - Real-time search by topic titles, notes, and tags (`Cmd+F`).
  - Status filters (`All`, `Remaining`, `Completed`).
  - Interactive tag pills (filter topics by tags like `[Exam]`, `[Core]`, `[Lab]`, `[High]`).
- **Interactive Overview Dashboard:**
  - Overall semester progress ring and aggregate progress bar across all subjects.
  - Notion-style responsive subject card grid.
  - Drop zones for fast `.md` importing.
- **Export & Sync Back to Markdown (`Cmd+E`):**
  - Exports subjects back into standardized YAML + Markdown with updated `[x]` / `[ ]` task states, tags, and study notes.
- **100% Local-First & Zero Third-Party Dependencies:**
  - Powered natively by **SwiftData** with local SQLite persistence.
  - Custom, deterministic Swift Markdown parser and exporter without external dependencies.
  - Compatible with macOS 14.0+ (Sonoma or newer) on Apple Silicon and Intel.

## Building and Installing

### 1. Ready-to-Install DMG Disk Image:
The project generates a compressed disk image with a drag-and-drop installer:
- **DMG File:** [Syllabi.dmg](file:///Users/vedbadarshahi/Projects/Syllabus%20Manager/Syllabi.dmg)
- Double-click `Syllabi.dmg` in Finder, drag **Syllabi.app** into **Applications**, and launch it.

### 2. Run Directly:
You can immediately launch the built app bundle:
```bash
open dist/Syllabi.app
```

### 3. Rebuild App & DMG:
To build a fresh release binary, sign the app bundle, and generate a new `.dmg`:
```bash
./scripts/package_dmg.sh
```

To build and update the local installed app in `/Applications` in the same operation:
```bash
./scripts/build_and_install.sh
```

### 4. Run from Xcode:
1. Open the project folder or `Package.swift` in Xcode (`open Package.swift`).
2. Select target `Syllabi` and destination `My Mac`.
3. Press `Cmd + R` to run or `Cmd + U` to execute the test suite.

## GitHub Releases and Updates

The included workflow at `.github/workflows/release.yml` runs tests, builds `Syllabi.dmg`, and publishes it whenever you push a tag such as `v1.1.0`:

```bash
git tag v1.1.0
git push origin v1.1.0
```

Syllabi checks the public GitHub Releases feed at launch and when you return to the app, at most once every 15 minutes. **Check for Updates** in the sidebar checks immediately. For a signed release, **Update** starts the download. **Install and Relaunch** saves open changes and replaces the app bundle while preserving the existing SwiftData store. After installing a different version, Syllabi shows **What’s New** once.

### Enable installation and relaunch

1. Run `swift package resolve`, then use Sparkle’s `.build/artifacts/sparkle/Sparkle/bin/generate_keys --account syllabi` to create and store the signing key in Keychain.
2. In GitHub repository settings, add the printed public key as the Actions variable `SPARKLE_PUBLIC_ED_KEY`. Keep the private key in Keychain and retain a secure backup.
3. Build locally with `SPARKLE_PUBLIC_ED_KEY` and `RELEASE_VERSION` set, then run `bash scripts/sign_appcast.sh`. Push the version tag and attach `Syllabi.dmg` and `dist/appcast.xml` to its GitHub release. Actions checks the build and leaves publication to the signer. If you explicitly configure a matching private key as the Actions secret `SPARKLE_PRIVATE_ED_KEY`, Actions can sign and publish both files.
4. Install the first Sparkle-enabled build manually. Later versions with the same signing key can be downloaded, installed, and relaunched from the app.

Create each release with a new version tag:

```bash
git tag -a v1.1.0 -m "Release 1.1.0"
git push origin v1.1.0
```

For public distribution, Apple Developer ID signing and notarization handle macOS Gatekeeper. The packaging script accepts an optional `SYLLABI_SIGN_IDENTITY` from the local or CI keychain. Sparkle’s separate signing keys authorize the appcast and installer.
